2) 와이드 이미지형   ← 오기로 보입니다

2. 브랜드메시지 캐러셀 유형의 코드 충돌

전체 기능 맵과 개별 슬라이드의 코드가 어긋납니다.

유형 전체 기능 맵 개별 슬라이드
캐러셀 피드형 0-1-4 0-1-6
커머스형 0-1-5 0-1-5
캐러셀 커머스형 0-1-6 0-1-6

캐러셀 피드형과 캐러셀 커머스형이 같은 코드 0-1-6을 쓰고 있습니다. 개발팀이 화면을 매핑할 때 충돌합니다. 가이드 자체는 코드를 노출하지 않지만, 핸드오프 매핑표를 확정하려면 정리가 필요합니다.

3. 구독료 결제일이 두 가지

출처 내용
마이페이지 > 구독 관리 "결제일은 전월 28일"
슈퍼어드민 > 구독료 결제 내역 "요금제는 매월 20일 청구"

고객이 직접 보는 숫자입니다. 하나로 확정해 주세요. 참고로 20일로 정한 이유가 "미납 시 10일 버퍼"라고 적혀 있어, 두 날짜가 서로 다른 것을 가리키는 것일 수도 있습니다(청구일 vs 결제일). 그렇다면 용어를 구분해야 합니다.

위치 표기

알림톡은 스펙(14자)과 화면 캡션(0/8)이 반대로 어긋납니다. 브랜드메시지 기본 텍스트형도 스펙에 글자수 기재가 없습니다. 가이드에는 스펙 기준으로 쓰고 기본 텍스트형에는 [확인 필요]를 달아뒀습니다.

25자인지 30자인지 확정 필요합니다. 가이드에는 30자로 쓰고 주석을 달았습니다.

6. 강조표기형 타이틀 말줄임 시작 위치

  • 대부분 슬라이드: "안드로이드 2줄, 23자(24자부터 말줄임)"
  • 일부 화면 캡션: "안드로이드 2줄/23자(14자부터 말줄임)"

14자는 오타로 보입니다. 가이드에는 23자만 쓰고 말줄임 시작 위치는 뺐습니다.

7. 이미지 용량이 두 가지

위치 용량
알림톡 이미지 스펙 최대 500KB
아이템 하이라이트 이미지 화면 캡션 jpg,png / 최대 **5MB**
브랜드메시지 와이드 리스트·캐러셀 화면 캡션 jpg,png / 최대 **5MB**

알림톡과 브랜드메시지의 기준이 다른 것인지, 캡션이 잘못된 것인지 확인 필요합니다. 가이드에는 알림톡 500KB, 브랜드메시지 5MB로 썼습니다.

8. 와이드 이미지형 이미지 규격

  • 스펙: 이미지 사이즈 800*600(4:3), 10MB, JPG/JPEG/PNG
  • 미리보기 캡션: 2:1 (800*400 권장)

비율이 4:3인지 2:1인지 다릅니다. 가이드에는 800×600(4:3)으로 썼습니다. 동영상(3초 이상 / 1GB / AVI, FLV, MP4) 지원 여부도 화면에만 있고 스펙에 없어 가이드에서 뺐습니다. 지원한다면 추가해야 합니다.

9. 앱푸시 지원 여부

  • 채널 설정: 발송 채널 우선순위 기본값 1순위가 앱푸시
  • 콘텐츠 리포트·캠페인 상세: 채널 아이콘에 푸시알림 포함
  • 메시지 원본 v11: "앱푸시는 확장 예정"

가이드에서 앱푸시를 어떻게 다룰지 결정이 필요합니다. 지금 초안은 화면에 보이는 대로 목록에만 포함하고 별도 설명은 쓰지 않았습니다.

10. LTV 공식

출처 공식
기능 정의서 구매전환율 × 객단가 × 구매빈도 (3변수)
메시지 원본 v11 구매자 전환율 × 구매빈도 × 객단가 × 생애주기 (4변수)

제품이 실제로 계산하는 건 3변수입니다. 대외 메시지는 4변수를 씁니다. 가이드는 제품 기준(3변수)으로 썼습니다. 마케팅 문서와 설명이 달라지는 점은 인지하고 계셔야 합니다.

11. 일반 발송의 상/중/하 등급

리포트_캠페인 슬라이드에만 이런 표기가 있습니다.

발송 우선순위 표시 옵션
- 무조건 발송
- 일반 발송 (상/중/하)

다른 어느 슬라이드에도 일반 발송의 상/중/하 개념이 없습니다. 캠페인 생성 화면에도 없습니다. 실제 기능이라면 가이드에 반드시 들어가야 합니다. 리포트에만 있는 표기라면 삭제가 필요합니다.
