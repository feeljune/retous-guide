차단 발행 차단 — 전부 해소

#1 알림톡 메시지 유형 = 부가정보형 확정 화면 확정

콘텐츠 에디터 알림톡 「메시지 유형」 드롭다운: 기본형 · 부가 정보형 · 채널 추가형 · 복합형. 「와이드 이미지형」은 알림톡에 없음(브랜드메시지 쪽). 가이드 그대로 둔다.

#2 캐러셀 피드형 ≠ 캐러셀 커머스형 확정 화면 확정

브랜드메시지 「메시지 유형」 드롭다운 6종: 기본 텍스트 이미지형 · 와이드 이미지형 · 와이드 리스트형 · 커머스형 · 캐러셀 피드형 · 캐러셀 커머스형. 둘은 별개 항목. 문서의 0-1-6 중복은 문서 오기.

#3 구독료 결제일 = 매월 20일 확정 화면 확정 (양쪽 일치)

  • 슈퍼어드민 회사 상세: 「정기 결제일 매월 20일」 · 다음 결제 2026.10.20
  • 마이페이지 > 구독 관리: 「다음 결제일 2026.10.20」 양쪽 모두 매월 20일. 구자료의 「전월 28일」은 현행 아님. 가이드는 "매월 20일(다음 결제일 표기)"로 쓴다.

#4 버튼명 글자수 = 14자 확정 화면 확정

  • 알림톡 기본형 버튼: 0/14 "띄어쓰기 포함 14자 이내"
  • 브랜드메시지 기본 텍스트 이미지형 버튼: 0/14 동일 구자료 캡션의 0/8은 현행 아님. 가이드의 14자가 맞다. ※ 와이드/커머스/캐러셀 유형의 버튼명 글자수는 미세 확인 미완(대개 카카오 8자). 필요 시 추가 확인.

정리 발행 전 정리 — 해소

#5 와이드 리스트형 글자수 확정 화면 확정

  • 리스트1 내용: 0/25 (25자, 줄바꿈 1회) · 이미지 2:1(800×400)
  • 리스트2·3 내용: 0/30 "최대 30자, 줄바꿈 1회" · 이미지 1:1(800×800) → 리스트1 = 25자, 리스트2·3 = 30자. 가이드의 30(리스트2·3)이 맞고, 25는 리스트1 혼동이었음.

#7 이미지 용량 확정 화면 확정

브랜드메시지 와이드 이미지형 이미지: 최대 5MB (최소 500px, JPG/PNG). 가이드의 5MB가 맞다.

#8 와이드 이미지형 규격 확정 화면 확정 — 가이드 수정 필요

실제: 이미지 비율 1:1 ~ 2:1 · 최소 500px · 5MB · JPG/PNG. 내용 76자, 줄바꿈 최대 5개. → 가이드의 「800×600(4:3), 10MB」는 틀림. 「1:1~2:1, 최소 500px, 5MB, JPG/PNG」로 교체. → 동영상 지원 없음(이미지 JPG/PNG만). 가이드에서 동영상 언급은 빼는 게 맞다.

#11 일반 발송 상/중/하 확정 화면 확정 — 없음

캠페인 생성 「발송 우선 순위」 = 무조건 발송 / 일반 발송 2개뿐. 상/중/하 없음. → 리포트에만 있던 표기. 가이드에 상/중/하를 넣지 않은 현재 초안이 맞다.

추가 확정 — 가이드에 반영할 것

Delay Time (가이드 2-5) — 콘텐츠 단위 설정

  • Delay Time은 캠페인이 아니라 콘텐츠에 붙는다. 캠페인 상세의 콘텐츠 리스트에 D + N으로 표시됨.
  • 예약 캠페인: 콘텐츠 에디터 Delay Time = 1일 후 / 3일 후 / 5일 후 / 7일 후 / 직접 선택(일 단위). 캠페인 자체의 발송 유형은 「예약(오전/오후·시·분 발송 시각)」.
  • 실시간 캠페인: 캠페인 레벨에 시각/오프셋 입력 없음(트리거 발송). → 노션 기준 「실시간은 Delay Time 비움」과 일치. → 가이드 2-5는 "Delay Time = 콘텐츠별 발송 시점. 예약은 일(日) 단위 프리셋(1·3·5·7)+직접선택, 실시간은 트리거 즉시~분 단위"로 수정. 「예약 1~180일/실시간 3~60분」 단정 표현은 화면 프리셋 기준으로 완화.

Case A/B/C (개인화 변수 제외 로직) — 화면 확정

콘텐츠 에디터 「변수 선택하기」 모달에 명시:

  • 등록된 변수만 실제 값으로 치환. 미등록 변수 사용 시 콘텐츠 생성·테스트 발송 제한.
  • 저장된 데이터가 없으면 「대체 문구」로 발송 (변수마다 대체 문구 1개 설정).
  • 변수 값과 대체 문구가 모두 없는 고객은 발송 대상에서 제외. → Case A 값 있음=치환 / Case B 값 없음=대체 문구 / Case C 값·대체문구 모두 없음=제외. → 개발팀 질문 불필요. 가이드 4-6의 Case A/B/C는 「대체 문구 설정 여부」로 설명하면 됨.

취소선

콘텐츠 에디터 본문에 취소선 전용 버튼 없음 → 텍스트 규칙(\s) 방식으로 추정. 정확한 입력 규칙은 카카오/제품 문서 확인 필요(발행 차단 아님).

앱푸시 (#9)

광고 콘텐츠의 채널 선택에는 「브랜드 메시지」만 노출됨(이 화면 기준). 앱푸시는 스키마·메뉴에 존재하나 실제 광고 발송 노출은 확인 안 됨. 개발팀 확인 항목 유지.

아이템 리스트형 — 리스트 추가 시 700자 확정

  • 강조 유형만 아이템 리스트형으로 바꾸면 1,000자 그대로. **리스트를 실제로 추가하면 본문 /700, 부가정보 /200**로 줄어듦.
  • 가이드의 「1,300 → 1,000」은 숫자가 틀림. **「1,000 → 700, 부가정보 500 → 200」**이 맞다.
  • 이미지·헤더·하이라이트·리스트 중 1개 이상 필수. 리스트 추가 시 2개로 시작.

3차 — PJ 결정 + 화면 확인 (앱푸시 · LTV · 타게팅 · 운영 설정)

앱푸시 (03 #9) — 기능 미구현 (PJ 확정)

메뉴·채널 우선순위·채널 아이콘에 보이지만 발송 불가. 가이드에서 "아직 제공되지 않음"으로 명시하고, 검수 없는 채널 목록에서 뺐다.

LTV (03 #10) — 3변수 공식 (PJ 확정 + 화면 검산)

  • 공식: LTV = 구매전환율 × 객단가 × 구매빈도. 생애주기는 곱하지 않고 M0 → M+n 실측 누적으로 보여준다.
  • 화면: 분석 > LTV에서 날짜·숫자 박스를 클릭하면 「월간 코스트 상세」 패널이 열림 — 신규회원 · 최종 LTV · 구매전환율 · 객단가(ARPPU) 요약, LTV 성장 추이(이번 구간 증가/이전 누적), 구간별 표(구매전환율 · 객단가 · 구매빈도 · LTV).
  • 검산: 미스터밀크 2025/10 M0 = 60.43% × 29,770 × 1.45 ≈ 26,086 (화면 26,129, 반올림 차).
  • 패널 제목이 「월간 코스트 상세」 · 「2025/10 코스트」 — 「코호트」의 오기로 보임. 개발팀 전달 대상.

타게팅 프리셋 (03 #17) — 제공됨 (PJ 설명 + 화면 확인)

  • 메뉴 설정 > 조건식 관리(페이지 제목 「타게팅 설정」). 탭 2개:
    • 공통 타게팅 조건 — 읽기 전용, 67종(예약 53 · 실시간 14), 「선택 항목 일괄 다운로드」, 다운로드 열 완료. 미스터밀크는 67종 모두 완료.
    • 기업 타게팅 조건 — 다운로드한 조건. 상세 조건에 실제 값(「생일 7일 전」 등), 예상 모수, 적용 캠페인 수, 관리 아이콘 2개.
  • 흐름: 공통에서 다운로드 → 기업 조건식에서 세부 조건 수정 → 캠페인 생성에서 메인 타겟 퍼널 선택 시 목록에 보임 → 선택하면 끝.
  • 세부 조건 변경은 조건식 관리에서. 원본 수정보다 복사 후 수정 권장 — 한 조건식을 여러 캠페인이 공유하기 때문(PJ).

캠페인 생성 화면 (가이드 3-1 수정)
